# Play it! Playable musical instruments

Project Zomboid (Build 42) mod: the vanilla acoustic guitar, violin and trumpet play songs written in the Space Station 13 note format, note by note, heard by every player nearby. Zombies come to listen, wild animals run, tame ones that trust you come closer, and a Music skill decides how often you blunder.

Tests: `python tests/run.py` (Lua 5.1 via lupa).
